## Главная идея

Программа получает, обрабатывает и выводит информацию. Чтобы работать с данными, нам нужны имена, по которым можно обращаться к значениям в коде. Так появляется понятие переменной.

Для первого объяснения удобно представить переменную как подписанную коробку. Однако это лишь упрощённая аналогия. Точнее: в Python имя связывается с объектом. Имя — не сам объект, а способ обратиться к нему.

```python
age = 20
name = "Ali"
height = 1.78

print(name)
print(age)
print(height)
```

Здесь имена `name`, `age` и `height` связаны с разными значениями. Символ `=` в данном случае не означает математическое равенство. Он связывает результат выражения справа с именем слева. Поэтому `age = age + 1` — не алгебраическое уравнение: Python сначала вычисляет `age + 1`, а затем связывает полученное значение с именем `age`.

## Переменные и значения

Переменная — это имя, с помощью которого можно обратиться к значению в программе. Значение — сами данные, с которыми работает программа.

```python
score = 100
score = 125
print(score)  # 125
```

После второго присваивания имя `score` связано со значением `125`. Если старое значение `100` больше недоступно ни через одно имя, Python может освободить занятую им память. Конкретный механизм управления памятью зависит от реализации Python.

Несколько имён также могут ссылаться на один объект:

```python
first = [1, 2, 3]
second = first
second.append(4)

print(first)   # [1, 2, 3, 4]
print(second)  # [1, 2, 3, 4]
```

Список — изменяемый объект. Присваивание `second = first` не создаёт новый список: оба имени ссылаются на один и тот же объект. Это предварительное знакомство со ссылками на объекты и изменяемостью, к которым мы вернёмся позже.

## Зачем нужны типы данных?

Python не считает значения `25`, `25.0`, `"25"` и `True` одним и тем же типом. Они могут выглядеть похоже, но их типы и допустимые операции различаются.

```python
print(25, type(25))
print(25.0, type(25.0))
print("25", type("25"))
print(True, type(True))
```

Основные типы для начинающих:

- `int` — целые числа: `10`, `-4`, `0`.
- `float` — числа с плавающей точкой: `3.14`, `-0.5`.
- `str` — текст: `"Python"` или `'привет'`.
- `bool` — логические значения `True` и `False`.
- `NoneType` — тип значения `None`, которое часто обозначает отсутствие значения.
- `list` — упорядоченная изменяемая последовательность.
- `tuple` — упорядоченная последовательность, обычно неизменяемая.
- `dict` — отображение пар «ключ — значение».
- `set` — коллекция уникальных элементов.

Это не полный перечень типов Python, но его достаточно для начала.

## Примитивные типы и объекты

В разных языках программирования данные организованы по-разному. Например, Java рассматривает примитивные типы, такие как `int` и `boolean`, отдельно от объектных типов. JavaScript также различает примитивные значения — например, числа и логические значения — и объекты, хотя некоторые операции позволяют временно использовать для примитивов поведение, похожее на объектное.

У Python есть важная особенность: **почти все значения в Python представлены как объекты**. `int`, `float`, `bool`, `str`, `list`, `dict` и даже функции являются объектами. Поэтому нельзя напрямую переносить в Python понятие «примитивного типа» из другого языка без пояснений.

Даже обычное целое число является объектом:

```python
print(type(42))       # <class 'int'>
print(type(3.14))     # <class 'float'>
print(type("hello"))  # <class 'str'>
print(type(True))     # <class 'bool'>
print(type([1, 2]))   # <class 'list'>
```

На начальном этапе не нужно изучать все внутренние детали объектов. Важно запомнить: имя связывается с объектом, а тип объекта влияет на то, какие операции с ним имеют смысл.

## Что значит «храниться в памяти»?

Простая аналогия с ячейкой памяти помогает начать, но её не следует воспринимать как обещание о конкретном физическом адресе. Язык Python определяет связь имён и объектов, а размещение объектов в памяти зависит от реализации интерпретатора.

```python
x = 10
y = x
x = 20

print(x)  # 20
print(y)  # 10
```

Когда выполняется `y = x`, имя `y` связывается с текущим целочисленным значением `10`. Позже `x = 20` связывает `x` с другим объектом, а `y` по-прежнему связан со значением `10`.

С неизменяемыми объектами, например целыми числами, это легко понять. С изменяемыми объектами, например списками, несколько имён могут ссылаться на один объект, что иногда приводит к неожиданным результатам. Мы изучим это подробнее позже.

## В Python используется динамическая типизация

Python не требует заранее объявлять тип переменной. Одно имя может в разное время связываться с объектами разных типов.

```python
value = 10
print(value, type(value))

value = "ten"
print(value, type(value))

value = 10.5
print(value, type(value))
```

Сначала `value` связано с объектом типа `int`, затем — `str`, а потом — `float`. Это называется динамической типизацией.

Важно различать формулировки: сам объект не меняет свой тип. Число `10` остаётся целочисленным объектом. Когда выполняется `value = "ten"`, имя связывается с другим объектом другого типа. Фраза «тип переменной изменился» удобна в разговоре, но точнее сказать: «имя теперь связано с объектом другого типа».

## Функция `type()`

`type(value)` показывает тип переданного значения. Это особенно полезно новичкам, когда нужно проверить, является ли значение текстом, целым числом или другим типом данных.

```python
age = 18
price = 12.5
title = "Python"
is_ready = False
nothing = None

print(type(age))
print(type(price))
print(type(title))
print(type(is_ready))
print(type(nothing))
```

Результат обычно выглядит как `<class 'int'>`. Это также напоминает, что типы в Python сами являются объектами. В обычном коде для проверки типа часто используется и `isinstance()`, но разницу можно изучить позднее.

## Правила именования переменных

Имя должно помогать понять смысл данных. Следующие имена допустимы в Python:

```python
name = "Ali"
age = 20
AGE = 21
AGE2 = 22
_name = "internal convention"
first_name = "Ali"
firstName = "Ali"
user2 = "guest"
```

Основные правила синтаксиса:

1. Имя может начинаться с буквы или символа подчёркивания (`_`).
2. Имя не может начинаться с цифры.
3. После первого символа можно использовать буквы, цифры и подчёркивания.
4. Пробелы внутри идентификатора запрещены.
5. Регистр имеет значение: `name`, `Name` и `NAME` — разные имена.
6. Ключевые слова Python, например `if`, `for`, `class` и `return`, нельзя использовать как имена переменных.
7. Имена вроде `!age`, `(publicKey` или `private key` недопустимы, потому что не соответствуют правилам идентификаторов.

Примеры:

```python
# Допустимые имена
public_key = "abc"
_name = "Ali"
age2 = 18
FirstName = "Ali"

# Недопустимые примеры — оставьте их закомментированными:
# 5name = "Ali"        # начинается с цифры
# private key = "x"   # содержит пробел
# !age = 18             # начинается с !
# class = "Python"      # ключевое слово
```

Python поддерживает идентификаторы Unicode, поэтому имена не ограничены только английскими буквами. Однако в командных проектах часто предпочитают английские имена с ASCII-символами ради единообразия и совместимости с инструментами.

## Синтаксис и стиль — не одно и то же

`firstName` синтаксически допустимо. Но в Python распространён стиль `snake_case`: например, `first_name`. Это соглашение для читаемости и единообразия, а не требование синтаксиса.

Хорошие примеры:

```python
student_name = "Ali"
total_price = 150
is_logged_in = True
number_of_attempts = 3
```

Менее понятные примеры:

```python
x = "Ali"
tp = 150
a1 = True
n = 3
```

Короткие имена вроде `i` или `x` подходят для некоторых локальных контекстов, но обычно лучше выбирать осмысленные названия.

Начальное подчёркивание в имени вроде `_name` обычно служит соглашением «для внутреннего использования». Оно не делает значение автоматически приватным и не вводит строгих ограничений доступа.

Не стоит использовать имена встроенных объектов, например `list`, `str` или `type`, для собственных переменных. Например, после `list = [1, 2]` вызвать встроенную функцию `list()` в этой области видимости становится сложнее.
