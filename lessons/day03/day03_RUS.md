## 1. Где скачать Python и почему важно использовать официальный источник?

Первый вопрос при установке программы — где её взять? Официальный сайт Python — [python.org](https://www.python.org/). На странице загрузок предлагается установщик или Python install manager, подходящий для операционной системы. Не нужно скачивать установщик с неизвестных сайтов: официальный источник упрощает проверку версии, безопасности и правильного дистрибутива.

На дату проведения урока, 24 октября 2026 года, на странице Windows был доступен традиционный установщик Python 3.13.17. Версии Python со временем обновляются. По состоянию на 27 октября 2026 года на официальной странице версия 3.15.2 указана как самый новый функциональный релиз, а 3.14.10 — как обновлённая версия ветки 3.14; версия 3.13.18 является релизом безопасности, для которого установщик Windows не предоставляется. Поэтому важно проверить, какая версия установлена на компьютерах курса, и по возможности использовать в группе единую версию, подходящую для курса. Номера версий меняются, поэтому важнее помнить способ проверки версии, а не конкретный номер.

Официальная страница Python для Windows: <https://www.python.org/downloads/windows/>  
Общая страница загрузок Python: <https://www.python.org/downloads/>

### Установка в Windows

1. Откройте в браузере сайт `python.org`.
2. В разделе **Downloads** перейдите на страницу **Windows**.
3. Выберите версию Python, принятую для курса, и пакет, подходящий компьютеру. Большинство современных компьютеров с Windows используют 64-разрядную архитектуру x86-64, но для устройств ARM может потребоваться отдельный пакет.
4. Следуйте инструкциям по установке на официальной странице. Параметры в окне установщика могут отличаться в зависимости от дистрибутива и версии.
5. Если в классическом установщике есть параметр **Add python.exe to PATH** и по плану курса Python должен запускаться из командной строки командой `python`, удобно включить этот параметр. При использовании нового Python install manager или другого способа установки процесс может отличаться.
6. После установки откройте через меню «Пуск» **IDLE (Python 3.x ...)**. Обычно IDLE устанавливается вместе с основными компонентами Python.
7. Чтобы проверить установку, выполните команду `py --version` или `python --version` в Windows Terminal или Command Prompt. В зависимости от способа установки одна из команд может не работать; это ещё не означает, что Python отсутствует. Проверить установку можно и через IDLE в меню «Пуск».

Зачем проверять версию? На компьютере может быть установлено несколько версий Python. Например, команда `python` может запускать одну версию, а `py -3.13` — именно ветку 3.13. Позже версии могут иметь значение для пакетов, библиотек и некоторых возможностей синтаксиса.

### Установка и настройка — не одно и то же

**Установка** — размещение необходимых файлов программы на компьютере. **Настройка** — определение способа запуска программы, используемого интерпретатора и параметров среды. На начальном уроке сложная настройка не требуется: прежде всего нужно правильно запустить установленный Python, открыть IDLE и научиться сохранять файл.

Если на компьютере ученика установлено несколько версий Python, результаты команд `python --version`, `py --version` или `py -3.13 --version` могут различаться. Важный навык — определить, какой интерпретатор работает, а не снова и снова переустанавливать Python без проверки.

## 2. Python, IDLE и окно для написания кода — не одно и то же

Новички часто объединяют три понятия: язык Python, интерпретатор Python и IDLE. Они связаны, но выполняют разные задачи.

**Python** — язык программирования, на котором пишут текст программы.  
**Интерпретатор Python** — программное обеспечение, которое читает и выполняет код Python.  
**IDLE** — простая интегрированная среда разработки, поставляемая вместе с Python. Она объединяет Editor для написания кода, Shell для непосредственного выполнения команд и некоторые инструменты проверки и отладки.

IDLE — не единственный способ писать на Python. Позже ученики смогут использовать VS Code, PyCharm или другие редакторы. Но для новичков IDLE удобна: обычно она не требует сложной отдельной настройки и устанавливается вместе с Python.

При запуске IDLE обычно появляется окно **Python Shell** с тёмным или светлым фоном. В нём есть приглашение `>>>`. Оно означает, что Python ожидает интерактивную команду. Само приглашение вводить не нужно. Если курсор находится после `>>>`, можно ввести короткое выражение, например `2 + 3`, и после нажатия Enter результат появится сразу.

Но если нужно написать программу из нескольких строк и сохранить её, вместо ввода всего кода в Shell откройте отдельное окно **Editor** через **File → New File**. Полезно с самого начала различать назначение этих окон:

- **Shell:** проверка коротких команд, быстрый просмотр результатов и небольшие эксперименты.
- **Editor:** написание, сохранение, изменение и последующий повторный запуск текста программы.

Shell — не плохое и не неправильное место. Наоборот, это полезный инструмент. Главное — понимать, когда выполняется временный эксперимент, а когда пишется программа `.py`, которую необходимо сохранить.

## 3. Окна IDLE и их различия

### Окно Shell

Shell обычно открывается при запуске Python. Оно выполняет введённое пользователем выражение или команду и показывает результат. Например:

```pycon
>>> 2 + 3
5

>>> print("Привет")
Привет
```

В Shell команды и результаты отображаются интерактивно. Однако не следует считать, что команды из истории Shell автоматически сохранены в файле `.py`. Строки, введённые в Shell, не управляются так же, как обычный файл Editor. Если они понадобятся позже, скопируйте их в файл Editor или сразу пишите код в Editor.

### Окно Editor

Editor предназначен для написания и редактирования файлов Python. Откройте его через **File → New File**. Напишите код и сохраните файл с помощью `File → Save` или `Ctrl+S`, например под именем `hello_world.py`. Расширение `.py` указывает, что файл содержит исходный код Python.

Сохранённый файл Editor можно запустить через **Run → Run Module** или, как правило, клавишей `F5`. При необходимости IDLE предложит сохранить файл, а затем выполнит его в Shell. Так ученики увидят, что Editor — источник кода, а Shell — место, где отображается результат запущенной программы.

### Почему нужно сохранять файл с самого начала?

Если код остаётся только во временной сессии Shell, после выключения компьютера или перезапуска Shell может быть трудно точно восстановить выполненные действия. Файл `.py` сохраняется на диске. Его можно снова открыть, отредактировать, отправить другому человеку и добавить в репозиторий GitHub. Поэтому в ходе курса примеры кода каждого занятия будем сохранять в папке `examples/dayXX/`.

## 4. Для чего нужны меню IDLE?

Меню IDLE отличаются в зависимости от активного окна. В Windows и Linux у окон Shell и Editor есть собственные меню. Поэтому пункт меню, видимый в одном окне, может находиться в другом месте или отсутствовать в другом окне. Учить нужно не механическому запоминанию названий, а пониманию назначения команд. Официальная документация IDLE подробно описывает каждое меню: <https://docs.python.org/3/library/idle.html>.

### File

Это меню управляет действиями, связанными с файлами и окнами.

- **New File:** открывает новое пустое окно Editor. Используем его для написания первой программы.
- **Open:** открывает существующий файл с диска.
- **Open Module:** помогает найти модуль в путях поиска Python. На начальном этапе не требуется пользоваться этим каждый день.
- **Recent Files:** список недавно открывавшихся файлов.
- **Save:** сохраняет текущий файл.
- **Save As:** сохраняет файл под другим именем или в другом месте. Полезно, когда нужно назвать новую программу.
- **Close / Exit:** закрывает текущее окно или IDLE. Если есть несохранённые изменения, не игнорируйте предложение сохранить их.

Точное расположение команд меню может немного отличаться в разных версиях IDLE.

### Edit

Это меню предназначено для редактирования текста.

- **Undo / Redo:** отмена или повтор последнего изменения.
- **Cut / Copy / Paste:** вырезание, копирование и вставка текста.
- **Select All:** выделение всего текста в окне.
- **Find / Find Again:** поиск слова или символа в тексте.
- **Replace:** замена найденного текста другим.
- **Go to Line:** переход к определённой строке файла.

Для новичка наиболее полезны команды Undo, Copy, Paste, Find и Select All.

### Shell — только в окне Shell

Меню Shell управляет интерактивной средой.

- **View Last Restart:** помогает найти место, с которого Shell был перезапущен в последний раз.
- **Restart Shell:** перезапускает интерактивную среду; прежнее состояние Shell и переменные могут быть потеряны.
- **Previous History / Next History:** переход по ранее введённым командам.
- **Interrupt Execution:** пытается остановить команду, которая выполняется слишком долго или не отвечает.

Restart Shell не удаляет Python с компьютера — оно только обновляет текущую интерактивную сессию.

### Debug — главным образом для поиска ошибок

Инструменты меню Debug помогают выяснить, почему программа не выдаёт ожидаемый результат.

- **Debugger (toggle):** включает или выключает запуск программы через отладчик.
- **Stack Viewer:** помогает просмотреть последовательность вызовов в момент ошибки.
- **Auto-open Stack Viewer:** управляет автоматическим открытием Stack Viewer при некоторых исключениях.
- **Go to File/Line:** помогает перейти к файлу и строке, указанным в сообщении об ошибке.

На первом уроке необязательно пользоваться всеми этими инструментами. Пока достаточно знать, что существуют средства для исследования ошибок, а не только для переписывания кода наугад. К отладчику мы вернёмся позже.

### Options

Меню Options предназначено для настройки внешнего вида и предпочтений IDLE. В разделе **Configure IDLE** можно изменить размер шрифта, цвета, сочетания клавиш, стартовое окно, некоторые параметры редактирования и дополнительные источники справки. В Editor также могут быть доступны настройки отображения, например нумерация строк.

Не нужно менять каждую настройку. Достаточно знать, как увеличить шрифт, если текст слишком мелкий, и сделать код удобным для чтения.

### Window

Это меню помогает переключаться между открытыми окнами Shell и Editor. Если открыто несколько файлов `.py`, можно быстро перейти к нужному окну. Чтобы понять назначение меню, достаточно одновременно открыть Shell и Editor.

### Help

Меню Help предоставляет доступ к справке и документации.

- **About IDLE:** информация об IDLE и её версии.
- **IDLE Help:** документация об окнах, меню и использовании IDLE.
- **Python Docs:** открывает официальную документацию Python; в зависимости от настроек может открыться локальная копия или документация в браузере.
- **Turtle Demo:** открывает примеры на основе модуля Python `turtle`. Позже они могут пригодиться для интересных графических примеров.

### Меню Format и Run, которые могут отображаться в Editor

В окне Editor ученики могут увидеть дополнительные меню **Format** и **Run**. Это нормально.

**Format** помогает упорядочивать отступы блоков кода, превращать выделенные строки в комментарии или убирать комментарии, а также выполнять некоторые операции форматирования. Это меню станет полезным, когда изучение отступов Python приобретёт особое значение.

Меню **Run** используется для запуска и проверки файла из Editor.

- **Run Module:** проверяет текущий файл программы, при необходимости сохраняет его и выполняет в Shell.
- **Check Module:** помогает обнаружить некоторые синтаксические проблемы до запуска файла.
- **Python Shell:** открывает окно Shell или выводит его на передний план.

Главная привычка на первых уроках: `File → New File`, написать код, сохранить его как `.py` и запустить через `Run → Run Module` или `F5`.

## 5. Первая программа — Hello World!

Откройте новое окно Editor и напишите:

```python
print("Hello World!")
```

Сохраните файл под именем `hello_world.py` и нажмите `F5`. В окне Shell появится результат:

```text
Hello World!
```

Сначала это может выглядеть просто как одна строка текста. На самом деле успешный запуск проверяет сразу несколько вещей: Python запускается, синтаксис кода правильный, Editor умеет сохранять файл, IDLE передаёт его на выполнение, а результат отображается в Shell.

### Почему именно «Hello World!»?

Это исторически сложившаяся традиция программирования. В начале 1970-х годов Брайан Керниган использовал простой пример, выводящий приветствие, в руководстве по языку программирования B. Позже пример широко распространился благодаря книге *The C Programming Language*, написанной совместно с Деннисом Ритчи. Сегодня многие курсы продолжают эту традицию. Синтаксис Hello World в разных языках отличается, но цель похожа: написать простейшую работающую программу в установленной среде и показать вывод результата.

Текст необязательно должен быть именно `Hello World!`. Подойдут также `Hello, world!` или `Salom, dunyo!`. Главное, чтобы ученик понял связь между написанием программы, её запуском и просмотром результата.

### Что такое `print`?

`print()` — встроенная функция Python. По умолчанию она выводит текстовое представление переданных объектов в стандартный поток вывода, которым обычно является окно Shell. Внутри скобок указываем, что нужно вывести. Текстовое значение называется строкой (string); обычно строка заключается в пару двойных кавычек (`"..."`) или одинарных кавычек (`'...'`).

```python
print("Hello World!")
print('Привет, мир!')
print("Мы изучаем язык программирования Python.")
```

Сами кавычки обычно не выводятся: они указывают Python, где начинается и заканчивается строковый литерал. Если кавычки нужны внутри текста, можно использовать другой вид внешних кавычек или escape-последовательности, которые будут изучены позже.

### Использование запятой и `+` с `print()`

Оба способа можно использовать для вывода нескольких частей, но они выполняют разные действия.

**Передача нескольких аргументов через запятую:**

```python
print("Hello", "World!")
print("Возраст:", 18)
print("Результат:", 2 + 3)
```

Каждый аргумент передаётся функции `print()` как отдельное значение. По умолчанию между аргументами добавляется один пробел. Результат:

```text
Hello World!
Возраст: 18
Результат: 5
```

Этот способ позволяет выводить число вместе с текстом без ручного преобразования числа в строку, поскольку `print()` отображает каждый переданный аргумент как текст.

**Объединение строк с помощью `+`:**

```python
print("Hello" + "World!")
print("Hello" + " " + "World!")
print("Python " + "курс")
```

Здесь `+` объединяет строки. Первый результат — `HelloWorld!`, потому что мы сами не добавили пробел. Второй результат — `Hello World!`.

Главное различие: запятая передаёт в `print()` несколько отдельных аргументов, а `+` объединяет совместимые значения в одно новое значение. Поэтому:

```python
print("Возраст:", 18)       # работает
# print("Возраст: " + 18)   # вызывает TypeError: str и int несовместимы
```

Если нужно использовать `+`, целое число можно преобразовать в текст:

```python
print("Возраст: " + str(18))
```

Пока `str()` только упоминается для знакомства; подробно мы изучим её на следующих занятиях.

### `sep` и `end` — управление `print()`

По умолчанию `print()` ставит один пробел между аргументами и переводит строку после каждого вызова. Это можно изменить с помощью параметров `sep` и `end` соответственно.

```python
print("2026", "10", "24", sep="-")
print("Ali", "Vali", "Hasan", sep=" | ")

print("Привет", end=" ")
print("мир!")
```

Результат:

```text
2026-10-24
Ali | Vali | Hasan
Привет мир!
```

`sep` определяет, что ставится между несколькими аргументами. `end` определяет, что добавляется после завершения вывода. Эти параметры необязательны; если их не указывать, используются значения по умолчанию. Пока достаточно поэкспериментировать с ними.

### Простые и полезные варианты `print()`

```python
print("Первая строка")
print("Вторая строка")

print()  # выводит пустую строку

print("2 + 3 =", 2 + 3)
print("A", "B", "C", sep=",")
```

Полная документация Python для `print()`: <https://docs.python.org/3/library/functions.html#print>.

## 6. Комментарии — пояснения внутри кода

Сначала код может казаться понятным, но по мере роста программы легко забыть, почему было принято то или иное решение. Комментарий — это пояснение внутри кода, предназначенное для программиста; Python не воспринимает его как команду для выполнения.

В Python обычный комментарий начинается с символа `#`. Весь текст от этого символа до конца строки считается комментарием.

### Комментарий на отдельной строке

```python
# Эта программа приветствует пользователя.
print("Привет!")
```

Такой вариант удобен для объяснения новой темы, сложной идеи или назначения кода. Комментарий не заставляет Python выполнять новое действие.

### Комментарий в той же строке, что и код

```python
answer = 2 + 3  # вычисляем сумму в этом простом примере
print(answer)
```

Комментарий после кода технически работает, но чрезмерное их количество может сделать код плотным и трудным для чтения. Если пояснение длинное, лучше вынести его на отдельную строку.

### Комментарий из нескольких строк

Обычный способ закомментировать несколько строк в Python — поставить `#` в начале каждой строки.

```python
# Перед выводом результата
# программа может вычислить переменную.
# Переменные мы изучим на следующем уроке.
```

Иногда это называют «блочным комментарием», но отдельного специального синтаксиса многострочного комментария здесь нет: это последовательность обычных комментариев в строках.

### Тройные кавычки — не всегда комментарий

Иногда можно встретить такой код:

```python
"""
Назначение этого модуля — показать примеры print().
Этот текст служит docstring модуля.
"""
```

Строка в тройных кавычках не является особой формой обычного комментария Python. Это многострочный строковый литерал. Если поместить его в соответствующее место в начале модуля, функции или класса, он будет **docstring** — строкой документации. Позже её можно увидеть с помощью таких инструментов, как `help()`. Если просто написать такую строку вместо комментариев `#`, в некоторых случаях она останется строковым литералом, который обрабатывается при выполнении.

Поэтому придерживайтесь следующих начальных правил:

- Используйте `#` для обычных пояснений и временных заметок.
- Используйте docstring в подходящем месте, если нужно документировать назначение модуля, функции или класса.
- Не объясняйте тройные кавычки как «многострочный комментарий Python» — технически это неверно.

### Каким должен быть хороший комментарий?

Комментарий не должен просто повторять код; он должен объяснять необходимый контекст.

```python
# Хорошо: объясняется причина.
# Результат должен отображаться пользователю на отдельной строке.
print("Вычисление завершено")
```

Следующий комментарий часто избыточен:

```python
# Вызываем функцию print
print("Привет")
```

Для начинающего ученика не обязательно категорично называть такой комментарий плохим. Но с ростом опыта следует стремиться объяснять, почему сделано именно так, а не описывать то, что и так видно из кода.

## 7. Самые распространённые ошибки

**Код написан не в том месте: в Shell вместо Editor или наоборот.** Помните: Shell предназначен для интерактивных команд, Editor — для файлов, которые нужно сохранять. Если код требуется сдать как файл `.py`, сохраните его из Editor.

**Приглашение `>>>` добавлено в код.** Не копируйте приглашение Shell в Editor. В Editor нужно писать `print("Hello World!")`, а не `>>> print(...)`.

**Файл сохранён как `.py.txt`, а не `.py`.** Windows может скрывать расширения. Проверьте имя файла и место сохранения. Полезно включить отображение расширений файлов в Проводнике.

**Изменения не сохранены.** После изменения кода нажимайте `Ctrl+S`. IDLE может напомнить о сохранении, но контролировать состояние файла следует самостоятельно.

**Запятая и `+` считаются одним и тем же.** `print("A", "B")` ставит пробел между аргументами; `"A" + "B"` объединяет строки и даёт `AB`.

**Число и строка объединены через `+`.** Выражение `"Age: " + 18` вызывает `TypeError`, потому что одно значение — строка, а другое — целое число. Используйте `print("Age:", 18)` или `print("Age: " + str(18))`.

**Неверно записан синтаксис комментария.** Обычный комментарий Python начинается с `#`. Символ `//`, используемый для комментариев в некоторых других языках, не является обычным маркером комментария Python.

**Ожидается, что кавычки появятся в выводе.** `print("Hello")` выводит `Hello`, а не кавычки. Кавычки обозначают границы строки в коде Python.

**Python установлен несколько раз.** Перед повторной установкой проверьте работающий интерпретатор с помощью `python --version` или `py --version`. Установок может быть несколько, но не нужно удалять их, не разобравшись в проблеме.
