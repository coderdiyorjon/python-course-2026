## Программа не может работать только с заранее заданными данными

Когда мы только начинаем изучать программирование, обычно выводим информацию на экран с помощью `print()`:

```python
print("Hello, world!")
print("Мы изучаем язык программирования Python.")
```

При каждом запуске эти команды выводят один и тот же результат. Данные заранее определены, поэтому в этом отношении программа является статической.

Однако реальные приложения часто нуждаются в такой информации, как имя пользователя, возраст, адрес электронной почты и другие данные. Переписывать код для каждого пользователя было бы нелогично. Программа должна уметь получать информацию от самого пользователя.

В Python для этого используется функция `input()`.

## `input()` — получение данных от пользователя

Функция `input()` приостанавливает выполнение программы и ожидает, пока пользователь нажмёт Enter. В качестве аргумента можно передать текст, который объясняет пользователю, что именно нужно ввести.

```python
name = input("Введите ваше имя: ")

print("Здравствуйте,", name)
```

Программа просит пользователя ввести имя, а затем присваивает введённое значение переменной `name`.

Ещё один пример:

```python
age = input("Введите ваш возраст: ")

print("Ваш возраст:", age)
```

Здесь есть один важный момент: **функция `input()` всегда возвращает значение типа `str`.**

Даже если пользователь вводит `18`, Python воспринимает это значение как строку `"18"`, а не как целое число.

Проверить это можно с помощью `type()`:

```python
age = input("Введите ваш возраст: ")

print(type(age))
```

Результат:

```text
<class 'str'>
```

Это различие становится особенно важным, когда программе необходимо выполнять математические вычисления.

## Зачем нужно преобразовывать типы данных?

Представим, что мы получили возраст пользователя и хотим приблизительно вычислить год его рождения:

```python
age = input("Введите ваш возраст: ")

birth_year = 2026 - age
```

Этот код не работает. Причина в том, что `2026` имеет тип `int`, а `age` — тип `str`. Python не может вычесть строку из целого числа, поэтому возникает ошибка `TypeError`.

Строки можно объединять с другими строками, но это не то же самое, что математическое сложение:

```python
age = "18"

print(age + "1")
```

Результат:

```text
181
```

Python объединил две строки. Следовательно, перед выполнением математических операций необходимо привести данные к подходящему типу.

## Преобразование типов данных

В Python есть несколько встроенных функций для преобразования значений из одного типа в другой. На начальном этапе чаще всего используются следующие:

- `int()` — преобразует значение в целое число, если это возможно.
- `float()` — преобразует значение в число с плавающей точкой, если это возможно.
- `str()` — преобразует значение в строку.
- `bool()` — преобразует значение в логическое значение.

Сначала рассмотрим обычные переменные без использования `input()`:

```python
number = "25"

converted_number = int(number)

print(converted_number)
print(type(converted_number))
```

Результат:

```text
25
<class 'int'>
```

Функция `int()` преобразовала строку, содержащую целое число, в настоящее целое число.

Теперь рассмотрим число с плавающей точкой:

```python
price = "19.99"

converted_price = float(price)

print(converted_price)
print(type(converted_price))
```

Результат:

```text
19.99
<class 'float'>
```

Можно также преобразовать число в строку:

```python
number = 100

text = str(number)

print(text)
print(type(text))
```

Результат:

```text
100
<class 'str'>
```

Это полезно, когда нужно объединить числовые значения с текстом.

### Преобразование не всегда заканчивается успешно

Если Python не может преобразовать значение в указанный тип, возникает ошибка.

Например:

```python
age = int("eighteen")
```

Строка `"eighteen"` не содержит числового представления, которое функция `int()` могла бы обработать. Поэтому Python вызывает ошибку `ValueError`.

Рассмотрим ещё один случай:

```python
number = int("18.5")
```

Здесь также возникает `ValueError`. Строка `"18.5"` содержит дробную часть и не является корректным представлением целого числа для `int()`.

Но следующие два случая отличаются друг от друга:

```python
print(int(18.5))
print(int("18.5"))
```

В первой строке `18.5` уже является значением типа `float`. Функция `int()` отбрасывает дробную часть и возвращает `18`.

Во второй строке `int()` не может напрямую преобразовать строку `"18.5"` в целое число, поэтому возникает `ValueError`.

Запомните: `int()` не округляет дробное число, а отбрасывает его дробную часть. Например, `int(-3.9)` возвращает `-3`.

В других ситуациях может возникнуть `TypeError`, если переданный объект не подходит для выполняемой операции. Например, преобразование `int(None)` невозможно.

Эти две ошибки имеют разные причины:

- `ValueError` — тип входного объекта может быть допустимым, но его значение невозможно преобразовать указанным способом.
- `TypeError` — тип переданного объекта не подходит для выполняемой операции.

Есть ещё один важный нюанс: преобразование текста с помощью `bool()` не интерпретирует слова `"True"` и `"False"` как логические литералы. Любая непустая строка, включая `"False"` и `"0"`, преобразуется в `True`. Поэтому передавать пользовательский текст напрямую в `bool()` для обработки текстовых логических значений — ненадёжный подход.

## Использование преобразования типов вместе с `input()`

Теперь объединим изученные понятия:

```python
name = input("Введите ваше имя: ")
age = int(input("Введите ваш возраст: "))

print("Имя:", name)
print("Возраст:", age)
print("В следующем году вам будет:", age + 1)
```

На этот раз текст, возвращаемый функцией `input()`, сразу преобразуется в целое число с помощью `int()`.

Следующая запись:

```python
age = int(input("Введите ваш возраст: "))
```

логически состоит из двух этапов:

1. `input()` получает текст от пользователя.
2. `int()` преобразует полученный текст в целое число.

Поэтому эта запись эквивалентна следующему коду:

```python
age_text = input("Введите ваш возраст: ")
age = int(age_text)
```

Если пользователь введёт `"eighteen"` или `"18.5"` вместо целого числа, программа завершится с ошибкой `ValueError`. На данном этапе важно понимать причину этой ошибки. В следующих темах можно будет изучить обработку подобных ситуаций с помощью `try` и `except`.

## Проблема вычисления года рождения по возрасту

Предположим, что мы знаем возраст пользователя и хотим вычислить год его рождения:

```python
age = int(input("Введите ваш возраст: "))

birth_year = 2026 - age

print("Вы родились примерно в", birth_year, "году.")
```

Такой расчёт может быть полезен во многих ситуациях, однако результат не всегда будет точным.

Почему?

Мы не знаем, наступил ли день рождения пользователя в текущем году. Например, человек, которому 20 лет на 29 октября 2026 года, мог родиться как в 2005, так и в 2006 году.

Следовательно, только по возрасту нельзя всегда определить точную дату рождения и даже точный год рождения. Для точного расчёта также необходимо знать день и месяц рождения.

Этот пример показывает ещё одну важную мысль: корректность программы зависит не только от кода, но и от того, достаточно ли предоставленных ей данных.

## `print()` и f-строки

В предыдущих примерах мы использовали запятые внутри `print()`, чтобы вывести несколько значений:

```python
name = "Ali"
age = 20

print("Имя:", name, "Возраст:", age)
```

Результат:

```text
Имя: Ali Возраст: 20
```

Этот подход удобен, поскольку `print()` принимает значения разных типов в качестве отдельных аргументов и обычно автоматически добавляет пробел между ними.

Однако в больших программах часто требуется выводить информацию в более структурированном и удобном для чтения виде. Для этого используются f-строки.

F-строки появились в Python 3.6. Их базовый синтаксис выглядит следующим образом:

```python
name = "Ali"
age = 20

print(f"Меня зовут {name}, мне {age} лет.")
```

Результат:

```text
Меня зовут Ali, мне 20 лет.
```

Префикс `f` в начале строки сообщает Python, что это форматируемая строка. Внутри фигурных скобок `{}` можно указывать переменные или выражения.

Например:

```python
a = 10
b = 5

print(f"{a} + {b} = {a + b}")
```

Результат:

```text
10 + 5 = 15
```

Внутри f-строки можно использовать не только переменные, но и выражения Python.

### Форматирование чисел

С помощью f-строк можно также выводить числа в более аккуратном формате:

```python
price = 19.9876

print(f"Цена: {price:.2f}")
```

Результат:

```text
Цена: 19.99
```

Спецификатор формата `:.2f` означает, что число будет отображено с двумя знаками после десятичной точки.

Ещё один пример:

```python
name = "Ali"
score = 95.5

print(f"{name} набрал {score:.1f} балла.")
```

Результат:

```text
Ali набрал 95.5 балла.
```

F-строки позволяют удобно объединять текст и значения в одной строке.

## Сравнение трёх способов

Все три примера ниже выполняют одну и ту же задачу:

```python
name = "Ali"
age = 20

# Использование запятых
print("Имя:", name, "Возраст:", age)

# Объединение строк
print("Имя: " + name + " Возраст: " + str(age))

# Использование f-строки
print(f"Имя: {name} Возраст: {age}")
```

Во втором варианте нам необходимо преобразовать `age` в строку с помощью `str()`. Python не позволяет напрямую объединить значения `str` и `int` с помощью `+`.

В подобных ситуациях f-строки обычно оказываются более удобными и понятными.

## Распространённые ошибки

Следующие случаи необходимо запомнить:

```python
age = input("Возраст: ")
print(age + 1)  # TypeError: нельзя сложить str и int
```

```python
age = int(input("Возраст: "))
print(age + 1)  # Работает, если пользователь ввёл целое число
```

```python
price = float("19.99")  # Корректно
```

```python
price = int("19.99")  # ValueError
```

```python
print("Возраст: " + 20)  # TypeError
```

```python
print(f"Возраст: {20}")  # Корректно
```
