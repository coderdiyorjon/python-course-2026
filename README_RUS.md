
# Базовый курс по Python

Комплексная учебная программа, предназначенная для изучения основ программирования на Python с нуля до уверенного уровня.

### 🎯 Цели курса

По завершении курса студент сможет:

* **Основы:** Понимать синтаксис Python и самостоятельно писать чистый код.
* **Данные:** Работать со структурами данных (списки, словари, множества, кортежи).
* **Логика:** Использовать условные операторы, циклы и создавать функции.
* **Файлы и модули:** Подключать сторонние модули и работать с файловой системой.
* **Тестирование:** Находить ошибки (дебаггинг), обрабатывать исключения и писать автотесты.
* **ООП:** Понимать и применять на практике принципы объектно-ориентированного программирования.
* **Практика:** Самостоятельно разработать и запустить полноценный проект на Python.

### 📁 Структура репозитория

* `lessons/` — Конспекты и теоретические материалы для каждого урока.
* `tasks/` — Практические упражнения и домашние задания.
* `examples/` — Примеры исходного кода, разбираемые на занятиях.
* `projects/` — Мини-проекты и файлы финального проекта.
* `tests/` — Автоматические тесты для проверки написанного кода.
* `docs/` — Дополнительная документация и инструкции.

### 🚀 Как начать

1. Скачайте (клонируйте) этот репозиторий на свой компьютер.
2. Следуйте инструкциям в файле `SETUP.md` для настройки рабочего окружения.
3. Откройте нужный урок в папке `lessons/` и изучите теорию.
4. Запустите и проанализируйте примеры кода из папки `examples/`.
5. Самостоятельно выполните задания из папки `tasks/`.

### 🏆 Финальный проект

В конце курса студенты разработают полноценную **«Систему управления библиотекой»**, применяя базовые концепции Python и принципы объектно-ориентированного программирования (ООП).
