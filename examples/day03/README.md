# Day 03 — Runnable examples

Run the scripts from the repository root directory.

```bat
python examples/day03/hello_world.py
python examples/day03/print_basics.py
python examples/day03/comments.py
```

If `python` is not recognized on Windows, try `py` or consult the course's `SETUP.md`. The command that works depends on how Python was installed and configured.

- `hello_world.py` is the smallest first program.
- `print_basics.py` compares separate arguments, `+`, `sep`, and `end`.
- `comments.py` demonstrates `#` comments and explains why a triple-quoted module docstring is not the same thing as a comment.

The scripts are deliberately small so students can predict the output before running them.
