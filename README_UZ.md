# Python Dasturlash Asoslari Kursi

Python dasturlash tilini noldan boshlab professional darajagacha o'rganish uchun mo'ljallangan mukammal o'quv dasturi.

### 🎯 Kurs Maqsadlari

Kursni muvaffaqiyatli yakunlagan o'quvchi quyidagi ko'nikmalarga ega bo'ladi:

* **Asoslar:** Python sintaksisini chuqur tushunish va toza, mantiqiy kod yozish.
* **Ma'lumotlar:** Ma'lumotlar tuzilmalari (list, dictionary, set, tuple) bilan ishlash.
* **Mantiq:** Shart operatorlari, sikllar va ko'p martalik funksiyalarni amaliyotda qo'llash.
* **Fayllar va Modullar:** Tashqi modullarni ulash va fayllar (o'qish/yozish) bilan ishlash.
* **Xatoliklar va Testlash:** Kodni tekshirish (debugging), xatolarni ushlash va avtomatlashtirilgan testlar yozish.
* **OOP (Obyektga yo'naltirilgan dasturlash):** Klasslar, inyeksiyalar va polimorfizm tamoyillarini tushunish va amalda qo'llash.
* **Amaliyot:** Noldan boshlab to'laqonli va mustaqil Python loyihasini ishlab chiqish.

### 📁 Repozitoriy Tuzilmasi

* `lessons/` — Har bir dars uchun nazariy ma'lumotlar va konspektlar.
* `tasks/` — Mustaqil ishlash uchun amaliy mashqlar va uy vazifalari.
* `examples/` — Dars davomida yozilgan tayyor kod namunalari.
* `projects/` — Kichik amaliyotlar va yakuniy loyiha fayllari.
* `tests/` — Yozilgan kodlarni tekshirish uchun avtomatik testlar.
* `docs/` — Kursga oid qo'shimcha hujjatlar va yo'riqnomalar.

### 🚀 Boshlash uchun qadamlar

1. Ushbu repozitoriyni o'z kompyuteringizga yuklab oling (Clone).
2. Dasturlash muhitini tayyorlash uchun `SETUP.md` ko'rsatmalariga amal qiling.
3. `lessons/` papkasidan tegishli darsni ochib, nazariyani o'rganing.
4. `examples/` papkasidagi tayyor kodlarni ishga tushirib tahlil qiling.
5. `tasks/` papkasidagi mashqlarni o'zingiz mustaqil bajaring.
