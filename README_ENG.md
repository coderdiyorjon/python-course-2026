
# Python Fundamentals Course

A comprehensive learning program designed to master Python programming from absolute beginner to advanced concepts.

### 🎯 Course Goals

By the end of this course, students will be able to:

* **Core Concepts:** Understand Python syntax and write clean, logical code independently.
* **Data Structures:** Effectively manage and manipulate collections (lists, dictionaries, sets, tuples).
* **Control Flow:** Utilize conditionals, loops, and build reusable functions.
* **File Handling:** Work with external modules and handle file input/output operations.
* **Debugging & Testing:** Identify bugs, handle exceptions, and write automated tests.
* **OOP (Object-Oriented Programming):** Understand and apply classes, inheritance, and polymorphism.
* **Development:** Build and deploy an independent, full-fledged Python project.

### 📁 Repository Structure

* `lessons/` — Theoretical notes and materials for each lesson.
* `tasks/` — Independent practice exercises and homework assignments.
* `examples/` — Ready-to-run source code examples discussed in class.
* `projects/` — Mini-projects and the final capstone project.
* `tests/` — Automated tests to verify code functionality.
* `docs/` — Additional documentation and guides.

### 🚀 Getting Started

1. Clone this repository to your local machine.
2. Follow the instructions in `SETUP.md` to configure your environment.
3. Open the relevant theory materials in the `lessons/` folder.
4. Run and analyze the code snippets provided in the `examples/` folder.
5. Complete the independent assignments located in the `tasks/` folder.

### 🏆 Final Project

As a capstone project, students will build a fully functional **Library Management System** applying Python fundamentals and Object-Oriented Programming (OOP) principles.
