# Teacher Checklist

This document is used for planning the course, logging sessions, and tracking the process of working with students.

### 📝 Before Class

- [ ] Define the lesson topic and objective.
- [ ] Review the lesson notes and theoretical materials.
- [ ] Prepare necessary code examples.
- [ ] Run the code examples in advance to ensure they work without errors.
- [ ] Check independent exercises and tasks.
- [ ] Verify necessary software and tools for the lesson.

### 🧑‍🏫 During Class

- [ ] Explain core concepts in simple terms.
- [ ] Demonstrate theory through practical examples.
- [ ] Note down student questions.
- [ ] Identify topics that students find difficult.
- [ ] Mark the topics that were actually covered.

### ✅ After Class

- [ ] Update the `lessons/dayXX.md` file based on the actual session.
- [ ] Review the tasks in the `tasks/dayXX.md` file.
- [ ] Place the necessary code examples written during class into `examples/dayXX/`.
- [ ] Add newly learned terms to the `Glossary` file.
- [ ] Note down topics that need to be reviewed in the next session.
- [ ] Push changes to the repository if necessary.

# Чек-лист преподавателя (Teacher Checklist)

Этот документ используется для планирования курса, ведения журнала занятий и отслеживания процесса работы со студентами.

### 📝 Перед уроком

- [ ] Определить тему и цель урока.
- [ ] Проверить конспекты урока и теоретические материалы.
- [ ] Подготовить необходимые примеры кода.
- [ ] Заранее запустить код (проверить на отсутствие ошибок).
- [ ] Проверить самостоятельные упражнения и задания.
- [ ] Проверить необходимые программы и инструменты для урока.

### 🧑‍🏫 Во время урока

- [ ] Объяснить основные концепции простым языком.
- [ ] Продемонстрировать теорию на практических примерах.
- [ ] Записать вопросы студентов.
- [ ] Определить темы, которые вызвали трудности у студентов.
- [ ] Отметить темы, которые были фактически пройдены.

### ✅ После урока

- [ ] Обновить файл `lessons/dayXX.md` в соответствии с прошедшим занятием.
- [ ] Проверить задания в файле `tasks/dayXX.md`.
- [ ] Поместить необходимые примеры кода, написанные на уроке, в `examples/dayXX/`.
- [ ] Добавить новые изученные термины в файл `Glossary` (Глоссарий).
- [ ] Записать темы, которые необходимо повторить на следующем уроке.
- [ ] При необходимости загрузить изменения в репозиторий (push).
