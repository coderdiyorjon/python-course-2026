# Lug‘at — 04-kun

- **O‘zgaruvchi (variable):** qiymatga murojaat qilish uchun ishlatiladigan nom.
- **Qiymat (value):** dastur ishlatayotgan ma’lumot.
- **Tayinlash (assignment):** ifoda natijasini nomga bog‘lash.
- **Obyekt (object):** Python qiymatlari va ular bilan bog‘liq xususiyatlar hamda amallarni ifodalovchi birlik.
- **Ma’lumot turi (data type):** qiymat qanday turga mansubligini va u bilan qanday amallar bajarilishini belgilovchi tur.
- **Dinamik tiplash (dynamic typing):** nomlar turli vaqtlarda turli turdagi obyektlarga bog‘lanishi mumkin bo‘lgan yondashuv.
- **`int`:** butun son turi.
- **`float`:** suzuvchi nuqtali son turi.
- **`str`:** matn turi.
- **`bool`:** `True` yoki `False` mantiqiy qiymatlari turi.
- **`NoneType`:** `None` qiymatining turi.
- **Mutable:** yaratilgandan keyin o‘zgartirilishi mumkin bo‘lgan obyekt.
- **Immutable:** yaratilgandan keyin mazmuni o‘zgartirilmaydigan obyekt.
- **Identifikator (identifier):** o‘zgaruvchi, funksiya yoki boshqa nomlangan obyekt uchun ishlatiladigan nom.
- **Kalit so‘z (keyword):** Python sintaksisida maxsus ma’noga ega so‘z.
- **`snake_case`:** so‘zlar kichik harflarda yozilib, pastki chiziq bilan ajratiladigan nomlash uslubi.


# Glossary — Day 04

- **Variable:** a name used to refer to a value.
- **Value:** data a program works with.
- **Assignment:** binding the result of an expression to a name.
- **Object:** a Python entity representing a value and its associated behaviour.
- **Data type:** a type that describes a value and the operations supported for it.
- **Dynamic typing:** a model in which names may be bound to objects of different types at different times.
- **`int`:** integer type.
- **`float`:** floating-point type.
- **`str`:** string/text type.
- **`bool`:** type of the logical values `True` and `False`.
- **`NoneType`:** type of the value `None`.
- **Mutable:** able to be changed after creation.
- **Immutable:** not changeable in place after creation.
- **Identifier:** a name used for a variable, function, or another named entity.
- **Keyword:** a word with a special role in Python syntax.
- **`snake_case`:** a naming style that uses lowercase words separated by underscores.


# Словарь — День 04

- **Переменная (variable):** имя, используемое для обращения к значению.
- **Значение (value):** данные, с которыми работает программа.
- **Присваивание (assignment):** связывание результата выражения с именем.
- **Объект (object):** сущность Python, представляющая значение и связанное с ним поведение.
- **Тип данных (data type):** тип, описывающий значение и допустимые операции над ним.
- **Динамическая типизация (dynamic typing):** модель, при которой имена могут в разное время связываться с объектами разных типов.
- **`int`:** тип целых чисел.
- **`float`:** тип чисел с плавающей точкой.
- **`str`:** строковый тип.
- **`bool`:** тип логических значений `True` и `False`.
- **`NoneType`:** тип значения `None`.
- **Изменяемый (mutable):** объект, который можно изменить после создания.
- **Неизменяемый (immutable):** объект, который нельзя изменить на месте после создания.
- **Идентификатор (identifier):** имя переменной, функции или другой именованной сущности.
- **Ключевое слово (keyword):** слово с особым значением в синтаксисе Python.
- **`snake_case`:** стиль именования, в котором слова пишутся строчными буквами и разделяются подчёркиваниями.
