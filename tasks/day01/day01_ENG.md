# Day 01 — Independent Tasks

### 🎯 Objective
To reinforce the concepts discussed in the first lesson, develop the ability to express thoughts clearly, and improve the skill of breaking down complex problems into simple steps (algorithmic thinking).

---

### Task 1. Human vs. Computer
Write an answer to the following question based on your own opinion and the knowledge gained in the lesson:

**"Who is smarter: a computer or a human?"**

In your answer, highlight the following:
* At least two strengths of a computer.
* At least two strengths of a human.
* The role a human plays in creating programs and controlling computers.
* How the development of Artificial Intelligence (AI) might change this comparison.

*(Note: Do not copy ready-made answers from the internet. Logically justify your own opinion).*

### Task 2. IT Professions
Choose **three** IT professions from the list below that interest you:
* Frontend Developer
* Backend Developer
* QA Engineer
* DevOps Engineer
* Data Analyst
* Cybersecurity Specialist
* UI/UX Designer
* Project Manager

For each selected profession, answer the following:
1. What does this specialist actually do?
2. What problems do they solve in a team?
3. To what extent do they need to write code?
4. What technical skills (programming languages, tools) are useful for them?
5. **Bonus:** Compare two of your chosen professions (e.g., how do Backend and QA collaborate?).

### Task 3. Algorithmic Thinking
Choose a simple everyday task that you perform regularly.
*(Example: Getting ready for work/school in the morning, making coffee, sending a picture to a friend via Telegram, etc.).*

Write **at least 6 clear steps (an algorithm)** to complete this task in a way that a computer could understand.

**Conditions:**
* The steps must be in a strict logical sequence.
* Each step should be simple and precise.
* Explain what error (bug) would occur if one of the steps were skipped.

### Task 4. Input, Process, Output
**Task:** Design the logic for a program that calculates a student's average grade across three subjects.

Write the following parts in text format (no coding required):
* **Input:** What data will be requested from the user for the program to work?
* **Process:** What arithmetic operation will be performed inside the program to find the average?
* **Output:** What result will be displayed on the screen to the user?

### Task 5. Terminology
Explain the meaning of the following terms learned in today's lesson **in your own words**, without copying from an IT dictionary (1-2 sentences for each is enough):
1. Program
2. Programming
3. Algorithm
4. Source code
5. Bug
6. Debugging

---

### 📋 Submission Criteria
* All answers must be written in your own words, clearly, and logically.
* Algorithm steps must be correctly ordered.
* The main tasks of IT professions must be clearly distinguished from one another.
* Input, Process, and Output sections must be logically separated.

**⚠️ Important:** Writing Python code is not required at all for these Day 01 tasks. The main goal is to build the logical thinking and systematic approach necessary for programming.
