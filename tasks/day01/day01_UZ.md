# Day 01 — Mustaqil topshiriqlar

### 🎯 Maqsad
Birinchi darsda muhokama qilingan tushunchalarni mustahkamlash, fikrni aniq ifodalash va murakkab muammolarni oddiy qadamlarga ajratish (algoritmik fikrlash) ko'nikmasini rivojlantirish.

---

### Task 1. Inson va Kompyuter
Quyidagi savolga o'z fikringiz va darsda olgan bilimlaringizga tayangan holda javob yozing:

**"Kim aqlliroq: kompyutermi yoki inson?"**

Javobingizda quyidagilarni yoritib bering:
* Kompyuterning kamida ikkita kuchli tomoni.
* Insonning kamida ikkita kuchli tomoni.
* Dasturlarni yaratish va kompyuterni boshqarishda inson qanday rol o'ynashi.
* Sun'iy intellekt (AI) ning rivojlanishi bu taqqoslashni qanday o'zgartirishi mumkinligi.

*(Eslatma: Tayyor javobni internetdan ko'chirmang. O'z shaxsiy fikringizni mantiqan asoslang).*

### Task 2. IT Kasblari
Quyidagi IT kasblaridan o'zingizga qiziq bo'lgan **uchtasini** tanlang:
* Frontend Developer
* Backend Developer
* QA Engineer
* DevOps Engineer
* Data Analyst
* Cybersecurity Specialist
* UI/UX Designer
* Project Manager

Har bir tanlangan kasb uchun quyidagi savollarga javob yozing:
1. Bu mutaxassis amalda nima ish qiladi?
2. Jamoada qanday muammolarni hal qiladi?
3. Kod yozish unga qanchalik darajada kerak bo'ladi?
4. Qanday texnik ko'nikmalar (dasturlash tillari, dasturlar) unga foydali bo'ladi?
5. **Qo'shimcha:** Tanlagan kasblaringizdan ikkitasini o'zaro taqqoslang (masalan, Backend va QA qanday hamkorlik qiladi?).

### Task 3. Algoritmik fikrlash
Kundalik hayotingizda muntazam bajaradigan oddiy bir vazifani tanlang.
*(Masalan: Ertalab ishga/o'qishga tayyorlanish, kofe tayyorlash, do'stingizga Telegram orqali rasm yuborish, va hokazo).*

Shu vazifani bajarish uchun kompyuterga tushunarli bo'ladigan darajada **kamida 6 ta aniq qadam (algoritm)** yozing.

**Shartlar:**
* Qadamlar qat'iy mantiqiy ketma-ketlikda bo'lishi shart.
* Har bir qadam sodda va aniq yozilishi kerak.
* Agar qadamlardan biri tushirib qoldirilsa qanday xatolik (bug) yuz berishini izohlang.

### Task 4. Input, Process, Output
**Vazifa:** O'quvchining uchta fan bo'yicha olgan baholarining o'rtacha qiymatini hisoblab beruvchi dastur mantiqini tuzing.

Quyidagi qismlarni matn ko'rinishida yozing (kod yozish talab etilmaydi):
* **Input (Kiritish):** Dastur ishlashi uchun foydalanuvchidan qanday ma'lumotlar so'raladi?
* **Process (Qayta ishlash):** O'rtacha bahoni topish uchun dastur ichida qanday arifmetik amal bajariladi?
* **Output (Chiqarish):** Ekran orqali foydalanuvchiga qanday natija ko'rsatiladi?

### Task 5. Atamalar izohi
Bugungi darsda o'rganilgan quyidagi atamalarning ma'nosini IT lug'atidan ko'chirmasdan, **o'z so'zlaringiz bilan** tushuntirib bering (har biri uchun 1-2 ta gap yetarli):
1. Dastur (Program)
2. Dasturlash (Programming)
3. Algoritm
4. Source code (Dastlabki kod)
5. Bug (Xatolik)
6. Debugging (Xatolarni to'g'rilash)

---

### 📋 Topshirish mezonlari
* Barcha javoblar o'z so'zlaringiz bilan, aniq va mantiqli yozilgan bo'lishi kerak.
* Algoritm qadamlari to'g'ri tartiblangan bo'lishi shart.
* IT kasblarining asosiy vazifalari bir-biridan aniq farqlab berilishi kerak.
* Input, Process va Output qismlari mantiqan to'g'ri ajratilgan bo'lishi kerak.

**⚠️ Muhim:** Ushbu 1-kun topshiriqlarida umuman Python kodi yozish talab qilinmaydi. Asosiy maqsad — dasturlash uchun eng zarur bo'lgan mantiqiy fikrlash va tizimli yondashuvni shakllantirishdir.
