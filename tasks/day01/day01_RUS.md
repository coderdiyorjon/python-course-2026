
# День 01 — Самостоятельные задания

### 🎯 Цель
Закрепить концепции, обсуждаемые на первом уроке, развить способность ясно выражать мысли и улучшить навык разбиения сложных проблем на простые шаги (алгоритмическое мышление).

---

### Task 1. Человек и Компьютер
Напишите ответ на следующий вопрос, основываясь на собственном мнении и знаниях, полученных на уроке:

**«Кто умнее: компьютер или человек?»**

В своем ответе раскройте следующее:
* Как минимум две сильные стороны компьютера.
* Как минимум две сильные стороны человека.
* Роль, которую играет человек в создании программ и управлении компьютерами.
* Как развитие искусственного интеллекта (ИИ) может изменить это сравнение.

*(Примечание: не копируйте готовые ответы из интернета. Логически обоснуйте свое личное мнение).*

### Task 2. IT-профессии
Выберите **три** IT-профессии из приведенного ниже списка, которые вам интересны:
* Frontend Developer
* Backend Developer
* QA Engineer
* DevOps Engineer
* Data Analyst
* Cybersecurity Specialist
* UI/UX Designer
* Project Manager

Для каждой выбранной профессии ответьте на следующие вопросы:
1. Чем на самом деле занимается этот специалист?
2. Какие проблемы он решает в команде?
3. Насколько ему необходимо писать код?
4. Какие технические навыки (языки программирования, инструменты) будут ему полезны?
5. **Дополнительно:** Сравните две из выбранных профессий (например, как взаимодействуют Backend и QA?).

### Task 3. Алгоритмическое мышление
Выберите простую повседневную задачу, которую вы выполняете регулярно.
*(Пример: подготовка к работе/учебе утром, приготовление кофе, отправка картинки другу в Telegram и т.д.).*

Напишите **как минимум 6 четких шагов (алгоритм)** для выполнения этой задачи так, чтобы это было понятно компьютеру.

**Условия:**
* Шаги должны быть в строгой логической последовательности.
* Каждый шаг должен быть простым и понятным.
* Объясните, какая ошибка (баг) произойдет, если пропустить один из шагов.

### Task 4. Input, Process, Output (Ввод, Обработка, Вывод)
**Задача:** Разработайте логику программы, которая вычисляет среднюю оценку студента по трем предметам.

Напишите следующие части в текстовом формате (писать код не требуется):
* **Input (Ввод):** Какие данные будут запрашиваться у пользователя для работы программы?
* **Process (Обработка):** Какое арифметическое действие будет выполняться внутри программы для нахождения среднего значения?
* **Output (Вывод):** Какой результат будет показан пользователю на экране?

### Task 5. Терминология
Объясните значение следующих терминов, изученных на сегодняшнем уроке, **своими словами**, не копируя из IT-словарей (достаточно 1-2 предложений для каждого):
1. Программа (Program)
2. Программирование (Programming)
3. Алгоритм (Algorithm)
4. Исходный код (Source code)
5. Ошибка (Bug)
6. Отладка (Debugging)

---

### 📋 Критерии сдачи
* Все ответы должны быть написаны своими словами, четко и логично.
* Шаги алгоритма должны быть правильно упорядочены.
* Основные задачи IT-профессий должны четко отличаться друг от друга.
* Части Input, Process и Output должны быть логически разделены.

**⚠️ Важно:** В этих заданиях первого дня писать код на Python совершенно не требуется. Главная цель — сформировать логическое мышление и системный подход, необходимые для программирования.
