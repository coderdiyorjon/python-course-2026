

# Урок 05 — Практические задания

**Темы:** `input()`, преобразование типов и f-строки

Эти задания предназначены для закрепления изученного материала. Цель — научиться получать данные от пользователя, правильно работать с типами данных и выводить результаты с помощью f-строк.

## 1. Программа-знакомство

Напишите программу, которая запрашивает у пользователя имя, фамилию и возраст. Выведите информацию в следующем формате:

```text
Здравствуйте, Ali Valiyev!
Вам 20 лет.
```

Требования:
- Имя и фамилия должны храниться как значения типа `str`.
- Возраст необходимо преобразовать в `int`.
- Для вывода результата используйте f-строку.

## 2. Возраст в следующем году

Запросите у пользователя его возраст и вычислите, сколько ему будет лет в следующем году.

Пример:

```text
Введите ваш возраст: 20
В следующем году вам будет 21 год.
```

Не забудьте преобразовать введённое значение с помощью `int()`.

## 3. Примерный год рождения

Запросите у пользователя возраст и вычислите примерный год рождения по формуле `2026 - age`.

Выведите результат примерно в таком формате:

```text
Вы родились приблизительно в 2006 году.
```

**Подумайте:** почему результат не всегда может быть точным? Какая неопределённость остаётся, если день и месяц рождения неизвестны?

## 4. Простой калькулятор

Попросите пользователя ввести два числа и выведите следующие результаты:

- Сумму.
- Разность.
- Произведение.
- Частное.

Требования:
- Получайте значения с помощью `float()`.
- Выводите результаты с помощью f-строк.
- Второе число не должно быть равно нулю при делении. Пока попробуйте отдельно проверить эту ситуацию и посмотреть, какая ошибка возникает при делении на ноль, даже до изучения условных операторов.

## 5. Расчёт покупки в магазине

Запросите у пользователя название товара, его цену и количество. Вычислите общую стоимость.

Пример:

```text
Название товара: Notebook
Цена: 12.5
Количество: 3

Товар: Notebook
Цена за единицу: 12.50
Количество: 3
Итого: 37.50
```

Требования:
- Цена должна иметь тип `float`.
- Количество должно иметь тип `int`.
- Общую стоимость вычислите с помощью `price * quantity`.
- Денежные значения выводите с двумя знаками после десятичной точки, используя f-строки.

## 6. Эксперименты с преобразованием типов

Выполните следующие выражения по отдельности и изучите результаты и возникающие ошибки:

```python
int("25")
int("25.5")
int(25.5)

float("25")
float("25.5")
float("hello")

str(25)
str(25.5)

bool("")
bool("False")
bool("0")
bool(0)
bool(1)
```

Попробуйте объяснить, почему каждое выражение возвращает именно такой результат. Также отдельно запишите выражения, которые вызывают ошибки.

## 7. Мини-проект: Карточка личных данных

Создайте небольшую программу, которая запрашивает у пользователя следующие сведения:

- Полное имя.
- Возраст.
- Город.
- Рост в метрах (например, `1.75`).
- Любимый язык программирования.

Используйте полученные данные, чтобы вывести аккуратно оформленную карточку профиля. Каждое значение должно иметь подходящий тип, а для формирования результата необходимо использовать f-строки.

Пример:

```text
========== PROFILE ==========
Name: Ali Valiyev
Age: 20
City: Tashkent
Height: 1.75 m
Favorite language: Python
=============================
```

## Дополнительные вопросы

1. Почему `input()` всегда возвращает значение типа `str`?
2. В чём разница между `int("12")` и `int("12.5")`?
3. Какой результат возвращает `int(12.9)` и почему?
4. В чём разница между `ValueError` и `TypeError`?
5. Почему нельзя определить точную дату рождения, зная только возраст человека?
6. Чем отличаются `print("Age:", age)` и `print(f"Age: {age}")`?
7. В какой версии Python появились f-строки?
8. Почему `bool("False")` возвращает `True`?
