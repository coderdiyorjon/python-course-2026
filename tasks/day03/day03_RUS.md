## 3. Различные формы print()

Запишите следующий код в отдельный файл `print_basics.py` и предскажите результат до его запуска.


## 6. Практическая проверка меню IDLE

Найдите и попробуйте каждое действие в IDLE:

- Открыть редактор через `File → New File`.
- Сохранить файл под новым именем через `File → Save As`.
- Отменить и повторить редактирование с помощью `Edit → Undo` и `Edit → Redo`.
- Запустить файл через `Run → Run Module`.
- Найти настройки шрифта или цвета в `Options → Configure IDLE`. Менять все настройки не обязательно.
- Переключиться между Shell и Editor через меню `Window`.
- Найти IDLE Help или Python Docs в меню `Help`.

Обратите внимание, что меню Shell может отображаться в окне Shell, а меню Run/Format — в окне Editor. Не ждите, что в обоих окнах появятся одинаковые меню.

## 7. Предсказание результатов вывода

Пока не запуская следующий код, запишите результат каждой строки в тетрадь или Markdown-файл. Затем запустите для проверки.


Почему в первой строке есть пробел, а во второй нет? Что произойдет, если не изменять `end`? Что выводит `print()`, если он вызывается без аргументов?
