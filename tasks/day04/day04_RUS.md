# День 04 — Самостоятельные задания

Эти упражнения закрепляют переменные, типы данных, `type()` и правила именования. Не ограничивайтесь угадыванием результата — постарайтесь объяснить, почему он получается именно таким.

## 1. Предскажите результат

До запуска кода запишите, что выведет каждый `print()`. Затем выполните код и проверьте ответы.

```python
value = 12
print(value, type(value))

value = "12"
print(value, type(value))

value = 12.0
print(value, type(value))

value = True
print(value, type(value))
```

Почему значения имеют разные типы, хотя некоторые из них выглядят похоже?

## 2. Повторное связывание имени

```python
number = 5
other = number
number = 8

print(number)
print(other)
```

Запишите результат и объясните, почему `other` не становится равным `8`.

## 3. Допустимые и недопустимые имена

Разделите имена на три группы: **допустимые**, **недопустимые** и **допустимые, но неудачные с точки зрения стиля**.

- `user_name`
- `2user`
- `_count`
- `first name`
- `class`
- `total2`
- `FirstName`
- `list`
- `user-name`
- `AGE`

Объясните причины недопустимости. Почему `list` синтаксически допустимо, но обычно не рекомендуется в качестве имени переменной?

## 4. Проверка типов

Напишите код, использующий `type()` для каждого значения:

- целое число;
- число с плавающей точкой;
- строка;
- логическое значение;
- `None`;
- список;
- словарь (`dict`).

Для каждого типа выберите собственный пример.

## 5. Похожие на вид значения

Объясните разницу между следующими значениями:

```python
a = 7
b = 7.0
c = "7"
```

Проверьте их типы. Попробуйте несколько операций и посмотрите, какие из них могут вызвать ошибку.

## 6. Два имени — один объект

```python
first = [1, 2]
second = first
second.append(3)

print(first)
print(second)
```

Объясните результат. Чем этот случай отличается от `number = 5; other = number; number = 8`? Пока достаточно объяснить слова «изменяемый» и «неизменяемый» своими словами.

## 7. Улучшите имена

Переименуйте переменные в соответствии с понятным стилем Python:

- `x` — возраст пользователя;
- `tp` — общая стоимость заказа;
- `a1` — признак того, что пользователь вошёл в систему;
- `n` — количество попыток.

## 8. Задание повышенной сложности

Создайте файл `student_profile.py`. Сохраните в отдельных переменных:

- имя ученика;
- его возраст;
- название курса;
- логическое значение, показывающее, продолжает ли он обучение;
- итоговую оценку, которая пока не назначена (`None`).

Выведите каждое значение и его тип с помощью `print()` и `type()`. Используйте стиль `snake_case`.

## Критерии оценки

- Предсказанный вывод сверяется с фактическим.
- Причины недопустимости имён объяснены правильно.
- Результаты `type()` интерпретируются верно.
- Повторное связывание имени отличено от ситуации, когда несколько имён ссылаются на один объект.
- В коде используются понятные имена.
